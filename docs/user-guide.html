Start and data mode

Run python3 run.py and open http://127.0.0.1:4173. Python 3.11+ and timezone data are sufficient. Use --data-dir and --port for an isolated workspace.

The starting portfolio is synthetic. Import or edit your own holdings and economics, then disable Synthetic demo input mode in Settings. Sources refresh only when requested. Paper execution and research acceptance are separate actions.

Research workflow

  1. Refresh Sources & evidence and inspect pending items.
  2. Classify facts, plans, forecasts, market-implied information and inference accurately. Accept evidence with explicit sources and first-known time.
  3. Use Theme discovery to screen headlines or request optional AI drafts. Check citations, counterarguments and invalidation. Accept a new theme unscored.
  4. Set its numerical component baseline only after review. Add a market proxy separately.
  5. Record lifecycle decisions and reasons; open the immutable HTML review in Run archive.

Market data

The ECB adapter supports reference currency pairs through a reviewed 90-day history. Choose a theme, base and quote currency, then fetch. Inspect the latest date, history and provenance. Review the anchor and hypothesis direction before accepting.

Reference rates are not executable quotes. Their exact historical release times are absent from the XML; the application conservatively records them as known at retrieval. Applying portfolio FX conversion rates is a separate action. NYSE and ECB/TARGET calendars cover 2026–2028; other venues need reviewed definitions.

WATCH and lifecycle

WATCH = clamp(25P + 25F + 20M + 20C + 10X − 10R, 0, 100). P = source support, F = fundamental tests, M = market confirmation, C = catalyst proximity, X = expression quality, R = independent counterdrivers. P/F/M/C/X accept 0, 0.5 or 1; R accepts 0, 1 or 2.

Below 45 is exploratory, 45–69.99 is research review, and 70+ is priority research. These are prioritization labels, not probabilities or trade instructions. Missing evidence and market observations stay missing. Two distinct adjacent eligible sessions are required for full market confirmation. Suspend, invalidate and archive override the score; resume requires an explicit decision.

Portfolio and scenario units

Funded equity/ETF, dirty-price bond, funded spot FX, option and futures models have explicit currencies and multipliers. Futures contribute unrealized P&L to NAV, not notional. Option vega is per contract per one volatility percentage point; do not multiply it by contract size again.

Currency stress includes cash and translates local asset P&L exactly once. Custom scenarios support key-rate DV01, spread DV01, signed basis sensitivity and incremental funding cost. Edit instrument economics in Portfolio and scenario assumptions in Portfolio risk. Missing sensitivities produce unavailable scenario results and can block paper controls.

Expression and paper decisions

Choose an instrument, direction and quantity to compare before/after risk and estimated costs. The application does not optimize quantities or generate them from a research score. A passing proposal may be staged; execution is a second action with current controls. A limit outside the simulated price remains unfilled. Retrying a filled order does not change balances again.

Broker snapshots support read-only quantity/cash reconciliation. They do not establish a broker connection or place orders.

Portfolio evaluation

Load the portfolio example in Evaluation to inspect the JSON contract. Replace it with aligned positive indices in the reporting currency and declare synthetic, historical ex-post or point-in-time data. Historical data need source URLs; point-in-time values need known-at timestamps.

Decisions known at close t execute at t+1 close, after that interval’s return. Holdings drift between decisions. Costs, borrowing/financing and terminal liquidation are included. Review benchmark return, Sharpe, Sortino, Calmar, drawdown and attributed P&L. This is an allocation diagnostic, not a derivative settlement simulator or proof of an edge.

Archive and recovery

Every committed research run retains exact input, previous state, configuration, portfolio, result and HTML. Settings offers workspace exports and current-state backups. For a full archive, stop the server and copy the entire data directory, including SQLite sidecar files. Restoring clears pending discovery/acquisition state; immutable run history remains in the destination database. Imported unfilled orders require new staging.

Optional AI

Set OPENAI_API_KEY and OPENAI_MODEL in the server environment. The app does not choose a model or load .env files. Explicit extraction/discovery actions share five attempted requests per day. Output caps are 2,000/4,000 tokens. Billing applies; these are not guaranteed spending caps.

AI output remains proposed inference. It cannot accept evidence, change scores or limits, create quantities, or place orders. Offline headline grouping remains available without credentials.
